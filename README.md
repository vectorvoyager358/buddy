# Buddy

Buddy is a lightweight native macOS desktop companion that provides wellness reminders while you work.

## Current Features

- Floating transparent desktop companion
- Always-on-top macOS panel
- Menu-bar controls
- Native macOS notifications
- Interactive reminders
- Done, snooze, and skip actions
- Basic animation states
- Modular SwiftUI and AppKit architecture

## Initial Use Cases

Buddy is designed to remind users to:

- Drink water
- Stand and stretch
- Rest their eyes
- Take short walking breaks
- Take user-configured supplements

## Technology

- Swift
- SwiftUI
- AppKit
- UserNotifications
- Combine
- Xcode

## Building the Project

1. Open `Buddy.xcodeproj` in Xcode.
2. Select the `Buddy` scheme.
3. Select `My Mac` as the run destination.
4. Press `Command + R`.

## Privacy

Buddy currently stores no data in the cloud and requires no account. All reminder data will be stored locally on the Mac.
